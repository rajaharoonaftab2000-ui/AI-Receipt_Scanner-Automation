AI Receipt Scanner Automation

An AI-powered receipt scanning automation built with n8n, Telegram, HTTP Request, JavaScript, and Google Sheets.

Overview

This automation allows users to send a receipt file through Telegram. The workflow processes the receipt, extracts important information using AI/OCR processing, and automatically stores the structured data in Google Sheets.

After processing, the workflow sends a confirmation message back to the user through Telegram.

Workflow

Telegram Trigger → Code in JavaScript → HTTP Request → Code in JavaScript → Append Row in Sheet → Send Text Message

How It Works

1. 📩 Receive a receipt file through Telegram.
2. ⚙️ Process the received file using JavaScript.
3. 🔍 Send the receipt data to an OCR/AI processing service through an HTTP Request.
4. 🤖 Process and structure the extracted receipt information using JavaScript.
5. 📊 Append the extracted data to Google Sheets.
6. 💬 Send a confirmation message back to the user through Telegram.

Features

- 📄 Receipt file processing
- 🤖 AI/OCR-powered data extraction
- ⚙️ JavaScript data processing
- 🔗 HTTP API integration
- 📊 Automatic Google Sheets data storage
- 💬 Telegram confirmation message
- 🔄 Fully automated workflow

Technologies Used

- n8n
- Telegram
- JavaScript
- HTTP Request / API
- AI / OCR
- Google Sheets

Use Case

This automation can help businesses and individuals reduce manual receipt data entry by automatically extracting important information from receipts and organizing it in Google Sheets.

It can be adapted for expense tracking, accounting workflows, financial record management, and other business automation use cases.
